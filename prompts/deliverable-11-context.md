# Deliverable 11 — Getting Started / Quickstart

## Purpose
Step-by-step onboarding tutorial. Takes a new developer from zero to their first trade on t+. Happy path only — no edge cases, no error handling deep dives.

## Audience
New developers who want to start building on t+ immediately. Assumes programming ability but no prior t+ knowledge.

## Target Structure
1. Prerequisites (accounts, API keys, SDK installation)
2. Connect to the API / initialize the SDK client
3. Deposit collateral
4. Place a first trade (market or limit order)
5. Check order status and position
6. (Optional) Withdraw funds
7. Next steps / links to deeper docs

## Depth Level
Tutorial-grade: exact commands, code snippets (Python via tpluspy), expected outputs. Every step should be copy-pasteable. Minimal explanation — just enough context to understand what each step does.

## Exclusions (covered in other deliverables)
- Full API reference → D2, D3
- Contract interaction → D4
- Full SDK reference → D5
- Fee details → D6
- Risk/margin details → D7
- Advanced trading → D8
- Settlement mechanics → D9
- Trust model → D10

## Word Count Target
Under 800 words of prose (code blocks don't count). Keep it short — users want to execute, not read.

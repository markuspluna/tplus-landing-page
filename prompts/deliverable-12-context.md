# Deliverable 12 — Glossary & Reference

## Purpose
Lookup resource for t+-specific and domain terminology, plus a quick-reference table of all API endpoints and contract methods. Not narrative — a reference you ctrl-F through.

## Audience
Anyone reading the docs who encounters an unfamiliar term or needs to quickly find an endpoint.

## Target Structure
1. Glossary (alphabetical, term → definition)
2. API endpoint quick-reference table (method, path, one-line description)
3. Contract method quick-reference table (function signature, one-line description)

## Depth Level
Definitions should be 1–2 sentences max. Endpoint/method tables: one row per item, no detailed parameter descriptions (those belong in D2–D4).

## Exclusions (covered in other deliverables)
- Detailed endpoint documentation → D2, D3, D4
- Conceptual explanations → D1, D7, D8, D9, D10
- Tutorials → D11
- Formulas and calculations → D6, D7, D13, D14

## Word Count Target
No hard cap — completeness matters. But each glossary entry should be 1–2 sentences, not a paragraph.

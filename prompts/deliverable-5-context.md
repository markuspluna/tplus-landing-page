# Deliverable 5 — tpluspy (Python SDK)

## Purpose
Full SDK documentation for the Python client library. Covers installation, configuration, and usage guides for every major workflow.

## Audience
Python developers building trading bots, analytics tools, or integrations with t+. Assumes programming competence but not t+ familiarity.

## Target Structure
1. Installation and dependencies
2. Authentication setup (API keys, signing)
3. Client initialization and configuration
4. Order management (create, cancel, query)
5. Market data queries
6. WebSocket streaming
7. Collateral/deposit/withdrawal operations
8. Error handling patterns
9. Complete method reference (or link to auto-generated docs)

## Depth Level
Usage-focused: code examples for every workflow, parameter descriptions, return types. Not just a method list — show how to use each feature with working examples.

## Exclusions (covered in other deliverables)
- Raw API endpoint details → D2, D3
- Smart contract direct interaction → D4
- Fee schedule → D6
- Risk/margin concepts → D7
- Trading concepts → D8
- Settlement concepts → D9
- Quickstart tutorial → D11

## Word Count Target
No hard cap — code examples should be complete and copy-pasteable. Minimize narrative between examples.
